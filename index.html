Merge Puzzle | Unity 2D

ClawsTruction

Developed as a prototype for the UTN Game Jam 2026 by a 4-person team. ClawsTruction is a precision-based merge puzzle built in Unity, where players construct specific target figures by dropping objects via a moving claw. As a QA Tester and Co-Developer, I ensured the stability of core mechanics and the reliability of complex custom systems across the game's levels.

Key Systems & QA Focus

  • Spawn Logic: Validation of dynamic prioritization queues for object generation across 3 distinct levels.
  • Physics Verification: Testing of collision boundaries, drop timing ranges, and trajectory limits within the Unity environment.
  • Algorithm Testing: Strict verification of the 100-point matching metric, accounting for proximity and rotation up to 45 degrees.
  • Progression Balancing: Evaluation of the 3-star reward system thresholds (40%, 65%, 85%) for difficulty tuning.

AI Agent | n8n Automation

AI Feedback Analyzer

JSON

An automated orchestration workflow built in n8n that acts as an intelligent customer feedback agent. It receives webhook data, utilizes local LLMs (Ollama/Gemma) to classify sentiment, and dynamically routes the execution to send tailored email responses or escalate negative feedback with AI-generated summaries.

Workflow Architecture

  • AI Sentiment Classification: Uses LangChain and an LLM to accurately categorize user feedback as Positive, Neutral, or Negative.
  • Dynamic Routing: Implements Switch nodes for conditional branching based on the AI's strict classification output.
  • Structured Output Extraction: Employs a secondary LLM with JSON parsers to extract the "root cause" and generate a 10-word summary for negative tickets.
  • Automated Escalation & Error Handling: Connects to Gmail APIs to notify administrators of critical issues or node failures instantly.
